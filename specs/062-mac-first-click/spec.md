# Feature Specification: Mac 窗口首次点击

**Created**: 2026-11-08 | **Status**: Focus correction installed and verified; broader intermittent symptom unconfirmed | **Branch**: main

## Problem

用户反馈 Mac 安装版在“探索 / 数字岛”等活动中偶发需要重复点击才能选中和提交。先前代表题的普通单击通过，但不能据此关闭间歇性问题。

本次确认一个可解释第一下点击丢失的配置条件：应用未启用 Tauri 的 `acceptFirstMouse`，默认值为 false；在 macOS 上，点击非活动窗口时不会同时将点击传给 WebView。该行为适用于整个应用，不能解释为仅探索存在的问题，也不能据此断定用户所有重复点击都来自窗口焦点。

## User stories

### US1 — 切回应用时一次点击生效（P1）

家长或孩子点击非活动应用窗口中的可用答案/操作按钮时，同一次点击既激活窗口，又执行原有操作。

验收：主窗口明确启用首次鼠标点击透传；在安装版中检查选择、提交、重玩和普通切回操作；每次单击仍只执行一次。

### US2 — 原有题目规则继续生效（P1）

启蒙与探索维持原单击规则，图片未就绪、观察阶段、完成后等禁用状态依旧生效；记忆活动失焦中断规则不变。

验收：现有活动/进度/导航/语音相关测试、构建和课程审计通过。选中与提交在代表题原生实测通过。

## Requirements

- FR-001：只修改已确认的 Mac 窗口首次点击配置；不以双击回调、模拟第二次点击或全局 pointerup 代替正常 click。
- FR-002：不改题目、资源、活动身份、答案、进度存储和页面事件处理。
- FR-003：保留“窗口已激活且资源已就绪时仍偶发丢失点击”的未确认边界，不把此配置修正称为全部症状已经复现或根治。
- FR-004：完成 `pnpm build`、`pnpm audit:curriculum`、相关现有测试、语音包审计及 `pnpm mac:install`，并重开真实应用验收。
- FR-005：在 main 工作区完成本地交付，更新 CHANGELOG、TODO；未请求提交或推送。

## Success criteria

安装版采用支持首次点击的 Mac 主窗口配置，常规单击操作与禁用规则不退化，验证记录区分配置证据、实际操作与尚未复现的用户症状。
