# Feature: 探索题面的插画、内容层次与版式优化

Date: 2026-09-23 | Branch: local dev

## Problem
用户反馈探索内容粗糙、配图抽象、缺少插画、内容组织与页间距不合理。现有批量首版将故事/生活事件文字栅格化，并用固定小尺寸呈现不同密度图示；儿童题面被侧栏、家长说明和能力术语挤压。

## Stories
- US1/P1：孩子先看问题与证据，再动手，最后查看反馈；题面具备稳定的信息层次、阅读宽度和间距，主要图片与选项足够大。家长说明不抢占主要操作区，随时可打开。
- US2/P1：故事事件、物品用途、观察变化和情境数学有符合题意的本地插画与实物卡；不把文字图片当成插画，不使用装饰背景泄露答案或挤压证据。精确几何图仍按确定性数据绘制。
- US3/P1：亲子活动按准备、步骤、观察记录组织，题族按清楚的活动路径组织，阶段/状态文案对儿童可理解。
- US4/P2：启蒙内容与进度保持完整，探索所有75组仍可进入。验证代表性六域、各交互、桌面和窄屏，导出语音，审计资源，安装并检查真实Mac应用。

## Acceptance
1. 不改启蒙题库、题目ID和已有完成事实；发现真实内容缺陷单独记录与修复，不以重写题量作为优化。
2. 每个探索题族完成一次呈现审查；明确保留精确图示、复用已有图、补充插画的范围。
3. 具体故事/生活动作优先本地插画；文字识读与语言推理允许文字卡，文字只出现一次。
4. 共用题面区分标题/问题/证据/操作/反馈，去掉默认反馈中的作者术语；父母提示与记录可展开；长活动分步、内容自然滚动。
5. 在1280×820、1024×700与375×812检查图/字/操作不重叠，无水平溢出；不能为了塞入一屏缩小答案图。
6. 图像源图、生成prompt、注册和使用位置可审计；不自动生成包含不可控数量/位置答案的场景。
7. build、curriculum/voice/image audits通过；mac:install完成，真实app界面验收，未推送main/dev。

## Validation boundary
技术验收不能代替6–8岁真实亲子观察。不承诺所有题族都变成故事，也不把术语删除解释成降低推理难度。
