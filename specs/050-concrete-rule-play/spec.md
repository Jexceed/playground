# 050 让规则看得见、动得起来

日期：2026-10-23。工作分支：main。需求依据：用户提供的“学会新规则”和“翻牌小机关”截图，小字和抽象示意无法帮助儿童独立理解。

## 用户故事与验收

### US1 / P1 看着圆片学规则

儿童先操作一个小例子：看见原来的圆片、添入的圆片，组合挑战再摆出同样的一份。然后面对不同起始数量，自己选出结果。

- 全部 L08 九题使用可数的本地圆片；不能只显示数字箭头。
- 示范逐步操作，可重复观看；示范数量与正式题分开，正式题不自动显示答案。
- 选项有等尺寸的圆片和醒目的数字，较大数量按五个一行整理。
- 保留原题 ID、revision、选项 ID/顺序、答案与进度；本轮只改善表征和操作支持。

### US2 / P1 直接翻动牌

儿童看到初始牌面和按序排列的操作图，点击对应的大牌翻面，再检查结果。

- 全部 L09 九题支持 3/4/5 张牌、1/2/3 步，重复翻同一张能回到原来。
- 操作图标出完整位置和目标牌，初始状态始终可回看。白面和黄面轮廓、尺寸相同。
- 自由操作，不自动代做或禁止错误；撤销恢复上次牌面，重来恢复初始牌面，提交沿用当前判定。
- 翻牌示范独立于作答，不改变尝试、答案或历史记录；完成后锁定作答。

### US3 / P2 清楚的文字和本机体验

- 两组主要短指令和操作标签至少 18px（窄屏 16px），触控目标至少 44px；布局不横向溢出。
- 操作可用键盘；减少动态效果设置下停用装饰动画。
- 新文案和示范朗读同步到本地 Edge 语音，无失败和回退；构建、课程审计和真实 Mac 安装后检查通过。
- 工程验收与真实儿童理解分开记录，后者仍需要亲子观察。
