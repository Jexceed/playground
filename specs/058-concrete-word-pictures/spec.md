# 058 词义图卡具体化

## US1 P1 具体物体与共同参照
“词语有朋友”中高/低、上/下、长/短、多/少共8种图卡重绘为成对情境：同一棵树旁的红风筝飞高/飞低；同一只猫在桌上/桌下；同款同尺度铅笔长/短；同款盘中同样大小的草莓6个/2个。每对只改变表达该词义的关键属性，保留同一相机、尺度和参照。文字仍只一层原词。

## US2 P1 检查类似问题
检查整组9题与全题库相同相对词的实际图卡引用；保留已清楚的开/关盒子、作为识字对象的“大”字，以及题目明确要求的数学/几何/颜色条比较。三道亲子活动继续真实操作，不伪造自动评分。记录发现、改绘、保留理由，不能宣称全库逐屏试玩。
