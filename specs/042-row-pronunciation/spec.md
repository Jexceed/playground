# 行列语音定音

## User request

“第 x 行”的“行”应读 háng，目前部分配音读成 xíng。修正同类语音问题并更新实际使用的安装包。

## User stories

- US1 (P1): 听题、选项、反馈与家长提示里的行列含义读 háng；行动、执行、自行车、平行、可行等词继续读 xíng。界面仍显示正确汉字。
- US2 (P1): 重新生成并实际使用修正后的本地语音，重跑生成器不会复用错误的旧配音；浏览器语音兜底和可选分段生成使用相同定音规则。

## Acceptance

- R1: 审查当前全部含“行”的语音，逐项区分行列和其他词义，明确修正范围与保留范围；不全局替换所有“行”。
- R2: 原题文字、答案、稳定 ID 与完成/续玩记录不变；语音合成输入与原始文本分别记录，可追溯。
- R3: 新合成输入必须使旧文件缓存失效，并生成不同资源 URL；未受影响的语音可继续复用。
- R4: 标准 Edge 声音和参数不变；脚本/清单对齐、失败为空、无 macOS say 或 mixed-local 兜底。运行时原始文字仍能命中新音频。
- R5: 用重点读音和保留词回归、语音媒体审计、课程审计、构建验证；保存可试听样例和实际检查边界，不把文件完整性当作全部读音试听。
- R6: mac:install 更新真实 Applications 应用，验证代表性听题入口与记录保留，更新 CHANGELOG/TODO/assets 和验证记录。

## Scope

本次集中处理“行”的上下文读音。采用已有 Edge 流水线，不新增收费语音服务、角色声音或题库重写。尚未储存的历史信息不推测，未逐条试听的其他多音字不宣称已全部解决。
