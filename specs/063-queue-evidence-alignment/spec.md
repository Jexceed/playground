# 063 数字岛题意与画面一致

**日期**：2026-11-14 · **分支**：main

## 用户问题

用户截图中的 N09 第 1 题问“小兔从左数第3，后面还有3位朋友”，画面却显示“从右数到小兔4位”和“两边都数到了我”。两种说法虽能算出同一结果，却未经说明就改变了给定条件；首阶段的讲解也直接套用了重复计数减一。

## 用户故事与验收

### US1（P1）：看见与题干相同的条件

- 第 1–3 题直接显示小兔从左数的名次、后面另有的朋友人数；小兔在左侧区域内，右侧区域与小兔不重叠。不得显示换算后的右侧名次或“两边都数到了我”。
- 第 4–6 题保留左右名次，第 7–9 题显示两组人数；只有这两类共同包含小兔的题使用重叠画面。
- 不提前展示总人数，不改题目 ID、题干给定条件、答案、选项次序和已有进度。

### US2（P1）：听见和题意一致的提示与解释

- 首阶段解释是左侧数到小兔的人数加后面人数，例如 3 + 3 = 6；提示和家长追问明确后面人数不含小兔。
- 后两阶段继续说明小兔被算了两次，总人数要减去重复的一次。
- 操作指令明确选择总人数；变更内容导出并生成本地标准 Edge 语音，脚本和 manifest 完全对齐、failures 为空。
