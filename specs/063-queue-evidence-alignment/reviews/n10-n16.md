# N10–N16 图文一致性审查

日期：2026-11-14。范围：探索数字岛的七个题组、每组九题，共 63 题。只读查看最终生成题目、实际渲染组件和数据模型，使用独立算式与 React 服务端渲染核对；未进行原生 UI 操作，未修改运行时代码。

## 发现

**N10 第 7–9 题缺少题干动作的画面表达。**题干分别要求从 23、34、45 中拿走一个，但画面复用第 4–6 题的静态数位模型，仅画出原来的长条和小块。模型没有“原来”的阶段标签，也没有拿走一小块的提示或动作。数字和答案本身没有算错；这是画面遗漏操作，容易把仍留在画面中的原数量理解为剩余数量。

成因：`src/curriculum/exploration/math.ts` 为第 4–9 题设置相同结构的 `placeValueModel`；`src/interactions/MathEvidence.tsx` 直接渲染 `PlaceValueBlocks`，没有步骤信息。建议给第 7–9 题增加显式的“原来／拿走一小块”语义，保留结果未知，不直接把图减成答案数量。修复后的原生显示由主交付验收记录覆盖。

通用指令“选出符合条件的一张图卡”用于数字选项，存在措辞不够具体的问题，但不计为数值或情境矛盾。
