# 054 两位朋友走格子的具象模型

## US1 P1 看图理解
全部9题直接显示红蓝朋友的角色插图、0–11连续格子、明确出发标记；每次向哪边走几格由跳格小模型表达，2/3/4次用足印表达。复用已经审查的兔子/狗狗PNG，红蓝底座加角色轮廓区别。全局框架/按钮样式保持。

## US2 P1 直接摆朋友
选择朋友后点数字格，也可拖过去作答。可以逐格推演或直接摆终点，不自动解题、不限制正确候选；共享撤销、清空、判分。两个角色允许同格且不遮挡。未作答显示出发位置但response仍为空。窄屏保留连续格子和44px以上点击目标，可局部横向滚动。

## US3 P1 语音与交付
保留清楚的起点、方向、步长、总次数口播，点击规则可重听。保留ID、revision、答案和进度；仅新增呈现元数据及适配新交互的短instruction。按要求导出、生成本地语音、build、curriculum/voice审计、浏览器与真实Mac安装验证。覆盖9题正确/错误、同格、undo/reset、窄屏。
