# UI合同

| 当前状态 | 主按钮 | 操作结果 |
| --- | --- | --- |
| 未答对 | 看看对不对/搭好了，试一试 | 不允许进入下一题 |
| 已答对，非末题 | 下一题 | 当前index+1，重置题内状态并读新题 |
| 已答对，末题且有漏题 | 去做还没完成的题 | 第一道漏题 |
| 已答对，末题全完成且有同主题下一组 | 下一组 | 下一组第1题 |
| 已答对，主题末组末题全完成 | 完成关卡 | 可见完成反馈，主按钮改为再玩一遍 |
| 完成反馈 | 再玩一遍 | 当前组第1题，历史完成不清除 |

“下一组”按钮title说明目的题组。按当前部分与主题的完整目录选择，搜索不影响顺序。手动重新选择任意题取消完成反馈。
