# Activity Session Contract

本契约是实施目标，非当前应用已支持的接口。字段详见 [data-model.md](../data-model.md)。

## User Navigation

一个“小小思考屋”启动与主页。按主题和能力路径显示活动，可调挑战与支持；不出现V1/V2、大龄专用独立软件或版本购买分流。
保留现有math/logic/graphic标识及原活动地址映射。新的memory/language/life通过注册表加入。
内部课程模块、schema版本和发行版本不暴露在儿童流程。

## Interaction Contract

| 类型 | 响应语义 | 必须验证的边界 |
|---|---|---|
| singleChoice | 一个optionId | 不能按展示下标判答案；换位不变 |
| multiSelect | 无序集合 | 少选、多选、取消、重复点击；不把空集合默认为未作答 |
| orderedPlacement | 有序槽位 | 同token可否复用；空白token与未填不同 |
| gridPlacement | 明确坐标到槽位 | 多空位、库存、替换/撤销；不按数组遍历巧合判定 |
| matching | 关系边集合 | 一对一/一对多由题定义，不按画线先后判定 |
| network | 无向连接及重数 | 点度数、至多双桥、轴向、不交叉、整体连通 |
| route | 起点与有序edgeId/方向 | 平行边、接续、抬笔、禁入、必经、重访、全部合法解 |
| construction | 部件位置/朝向 | 等价旋转、覆盖、重叠、可用部件和多解 |
| parentObservation | 家长观察条目 | 完成活动与能力表现分开，不产生伪自动分数 |

所有拖放提供点击选中再放置的等价操作，错误动作有可理解反馈。
submit只在明确提交时执行判定；选中、放置、撤销、暂存不增加“答错”次数。
skip为会话状态，不是答案选项；保留未完成并允许以后返回。
incomplete、incorrect、correct、needsParentObservation分别呈现；不能把“空白是一种正确图形”的情况与漏填混淆。

## Memory And Audio Contract

普通题可保持线索；记忆题按协议控制线索，不能靠CSS隐藏而让其他提示直接泄露内容。
ready → observe/listen → retain → respond → feedback → reflect。
- 展示时长从素材可见/声音开始实际播放后计算；载入中不计时。
- 听取阶段按本地音频完成事件推进；失败提供重试，不跳过必要信息。
- 展示/听取结束、进入保持阶段时即撤下记忆图/目标序列并停止刺激音频，作答阶段继续隐藏；重看/重听后重新计保持阶段并记support event。
- 切题、退出或后台立即取消旧音频和计时器；回到前台执行明确恢复策略。
- 参考截图里丢失的帮助音频需原创重建，不能假定截图文字足以恢复原任务。
- 图像/语音/指令的发布审核针对同一revision，禁止语音旧题干与新画面混用。
- 开放口述默认家长观察，无录音和云端语音判分依赖。
- 乐器/节奏等非语言刺激单独管理、校验，播放时避免讲解声掩盖线索；TTS朗读选项不能代替缺失的原始声音任务。

## Feedback And Parent Reflection

每个误选说明它违反的具体规则或可能的常见误判，避免只播放笼统“再想想”。
提示分为注意线索、拆解步骤、操作验证，不在第一步直接给出答案。
正确反馈可解释关键条件；多解题说明为何当前解法有效，并允许探索另一解。最大翻棋/最短路线等优化任务区分合法与最优，接受全部并列最优解。
家长追问至少覆盖“你看到了什么”“为什么这样做”或“换一种情况是否成立”中的适用内容。
开放任务采用关键线索/因果/顺序观察量规，不要求照背标准措辞。

## Content Acceptance

每个activity至少关联familyId和已检查的来源定位；来源与原创活动不必一一复制。
同题干答案本、截图、换排版共同指向canonicalProblem；已确认参数变化记录variant。
只有规则、交互、表征、反馈与难度台阶均通过复核，原题才可计入目标覆盖。
每个纳入题族达到矩阵声明的applicableStages与variantTargets。可重复训练默认三台阶、每阶三种变式；亲子观察默认三个不同条件的活动方案。减少台阶需明确适龄或能力理由和替代验收，不用同一故事换名凑数。
题族计数、独立活动数、可玩轮数、素材文件数分别统计。一个活动仅有一个primaryFamilyId，次级能力标签不用于跨族重复充配额。

## Release Contract

- build/audit使用同一catalog；未支持kind、无解、声明唯一却多解、缺资源/语音必须阻止导出。
- 平台同时检查交互、阶段、呈现能力、判定规则版本与资源；不满足时显式排除完整活动并列原因，禁止静默省略阶段或修改答案语义。singleChoice支持不等于体素/复杂矩阵呈现支持。
- 中文仍用zh-CN-XiaoxiaoNeural标准。英语任务另有locale、voice配置和覆盖审计，不能混淆“多语种合规配置”与旧的临时mixed local失败状态。
- 新本地体验的每次交付运行pnpm mac:install并打开真实应用验收；当前设计文档交付不触发重装。
