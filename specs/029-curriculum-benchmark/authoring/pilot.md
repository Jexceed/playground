# 首批24题的来源与独立验算

本批为原创题目，借鉴参考资料的思维操作与交互，不复制题图或照搬答案。完整题族建设仍在主任务清单中。

| 关卡 | 来源与采用的任务结构 | 本批递进 |
|---|---|---|
| 规则收纳盒 | S002 p4–5的集合选择；S099 p4–5、百花的多角度分类 | 同时满足两个属性、符合任一类、先选后排除、两组配对、恰有一个共同点 |
| 线索排排队 | S105 slide7–8、S112 p2–4的关系排序 | 三者传递、四者连锁、固定两端、紧邻、多种合法顺序、中间位置与紧邻联合 |

| 记忆摆一摆 | S002 p6–13的回忆重现、S005 p29的逆序任务 | 四项顺序、重复项目、二维位置、分组策略、空白位置、五项逆序 |

## 答案验证

多选穷举所有候选子集，按独立写出的颜色/形状谓词核对。排序穷举全部排列，按独立人工列出的合法队列核对。图形盘枚举行列约束的全部解，记忆按实际展示顺序/位置校验，最后一题明确反向。

排序六题解数为1、1、1、1、6、1；填格六题为1、1、2、1、4、1。多个合法解均可通过。空白卡是token，不等于未填槽位。

数据、判定与UI使用不同职责的模块，测试包含错误、漏填、未知/重复token、撤销、重用、后台中断及证据幂等。细目见[pilot-answer-audit.json](pilot-answer-audit.json)。

## 素材与语音

- 复用已注册的小猫、小狗、小兔、小熊及食物PNG。
- 10个几何/空白图卡由确定性SVG生成PNG，源码与运行图放在public/images/items/thinking-symbols/及source/，全部通过imageGallery注册。
- 题干、指令、规则、提示、反馈、亲子追问、图卡名称纳入统一语音导出。标准Edge zh-CN-XiaoxiaoNeural、rate -12%、pitch +2Hz。
- 1,958条清单与本地语音逐项对齐，生成与媒体审计问题数均为0；没有macOS say或mixed local。

## 使用限制

本批用于实际试玩和框架校验，未做6–8岁亲子难度校准。只有4组24题上线，不表示71个纳入题族已经完成。旧489题和原ID保持原值。
