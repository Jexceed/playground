# Feature Specification: 基于上实资料的思维活动扩展

**Feature Branch**: `dev`（独立工作目录）
**Created**: 2026-09-22
**Status**: 建设设计；课程与引擎尚未实施
**Input**: 一个应用，无需显式区分 V1/V2；扩展面向 6–8 岁的内容，全面对标本机“001上实幼升小资料合集”。

## User Scenarios & Testing

### User Story 1 - 连续的主题与难度路径 (Priority: P1)

孩子在“小小思考屋”中按主题和能力选择活动，旧内容与更有挑战的内容形成连续路径。家长可调整起点，不需要选择旧版、新版或另一应用。

**Why this priority**: 保留使用习惯和学习记录，让年龄扩展改善同一个产品。
**Independent Test**: 从旧存档续玩原题，在同一导航打开进阶任务后返回，记录正确。

**Acceptance Scenarios**:
1. **Given** 旧完成与续玩记录，**When** 更新后进入，**Then** 原记录保留；可确认的续玩位置恢复，无法确认旧题库版本的位置明确回到主题选择，不猜测映射，历史未知信息不被补造。
2. **Given** 已能完成基础活动，**When** 家长调整起点，**Then** 可直接进入更高挑战，年龄不构成硬性锁定。
3. **Given** 首次使用，**When** 浏览主题，**Then** 看到玩法、难度与前置能力提示，不出现 V1/V2 产品分流入口。

### User Story 2 - 操作、记忆和多解推理 (Priority: P1)

孩子能多选、排序、填格、连线和规划路径；记忆任务按需要先观察或听取，再隐藏线索作答。

**Why this priority**: 2022/2024 模拟材料的任务要求超过现有单选流程。
**Independent Test**: 完成多选集合、可重复候选的顺序回填、多空位规则填格、分阶段记忆和约束连线。

**Acceptance Scenarios**:
1. **Given** 多选题，**When** 选择、取消并提交，**Then** 按集合判定，不把点击顺序当答案。
2. **Given** 序列或填格题，**When** 使用同一图卡多次，**Then** 按该题的可复用、不可复用或库存数量规则处理。
3. **Given** 合法空白图形，**When** 提交，**Then** 它与未填写、暂存和跳过有不同含义。
4. **Given** 观察/听取后回忆任务，**When** 进入作答，**Then** 按题意隐藏线索；重看、重听可以使用，但计为使用支持。
5. **Given** 多种正确路线或拼法，**When** 提交任一合法解，**Then** 接受满足条件的解法，允许撤销、重试并解释约束。

### User Story 3 - 全面的能力递进 (Priority: P1)

孩子在数与量、关系与逻辑、图形与空间、记忆与注意、语言与表达、生活与探究六个能力域，逐步练习独立判断和组合迁移。

**Why this priority**: 解决题目偏简单，并覆盖参考资料中不属于数理图形的内容。
**Independent Test**: 逐项核验能力矩阵中的纳入题族，每族达到明示的适用台阶、变式目标及验收标准。

**Acceptance Scenarios**:
1. **Given** 纳入题族，**When** 查看课程，**Then** 达到矩阵规定的适用台阶与有效变式目标；可重复训练题族默认三个台阶、每阶三个变式，亲子活动或不适宜继续抽象的题族须有明确例外理由与替代验收。
2. **Given** 原有同名游戏，**When** 判断对标完成度，**Then** 以实际规则、交互和解释证据复核，不能凭名称计为覆盖。
3. **Given** 多属性变化题，**When** 出题，**Then** 难度来自规则、步骤或表示变化，题干简洁，画面不泄露答案。
4. **Given** 原资料为成人招考或高抽象题，**When** 提取可用能力，**Then** 用适合儿童的材料与逐级任务重建，不直接复制复杂原题。

### User Story 4 - 听说表达与亲子动手 (Priority: P2)

孩子能听故事、复述、解释依据、理解多步指令，并与家长完成测量、折纸、搭建和动作任务。

**Why this priority**: 合集明确包含语言、生活和动作内容，不能全部转换为选择题。
**Independent Test**: 完成故事复述、多步听指令、生活探究和亲子线下活动各一项。

**Acceptance Scenarios**:
1. **Given** 开放口述，**When** 孩子完成，**Then** 家长得到关键线索和追问建议，不以固定一句话为唯一答案。
2. **Given** 线下动作，**When** 家长确认，**Then** 记录为家长观察，不伪称设备自动测量动作质量。
3. **Given** 英文参考题，**When** 编写活动，**Then** 分清一般思维目标与英语听辨目标；英语目标具备对应语种音频，中文完成不能计为英语能力。
4. **Given** 缺失音频、歧义或过时常识，**When** 转化为课程，**Then** 核验并原创重建；未解决的题目不能上线。

### User Story 5 - 可解释的学习记录 (Priority: P2)

家长能区分独立完成、提示后完成、跳过和亲子观察，决定下次如何调整挑战。

**Why this priority**: 一次答对和完成标签不足以证明掌握。
**Independent Test**: 四类记录显示正确，刷新、内容重排和迁移后保持一致。

**Acceptance Scenarios**:
1. **Given** 多次尝试或提示，**When** 完成，**Then** 保留支持记录，反馈仍温和。
2. **Given** 题库重排，**When** 续玩，**Then** 按稳定题目身份找回位置，不跳到原序号的新题。
3. **Given** 只有历史完成记录，**When** 显示，**Then** 标为历史完成，不推断独立程度。

### User Story 6 - 可审计的全面对标 (Priority: P1)

维护者能从来源追到能力题族、课程、建设状态和验收证据，区分已有基础、需深化、新增、亲子延伸与仅作参考。

**Why this priority**: 资料有重复、缺项和不同适龄范围，“全面”必须逐项可核对。
**Independent Test**: 任一来源均有去向，任一纳入题族均能追到来源定位和实施任务。

**Acceptance Scenarios**:
1. **Given** 121 个来源文件，**When** 查索引，**Then** 每项有身份、指纹、定位方式、阅读范围及处理决定。
2. **Given** 题本、答案、分卷和重复截图，**When** 统计，**Then** 不把文件或页数累计为独立题量。
3. **Given** 首个试点完成，**When** 汇报，**Then** 仅报告该阶段完成，不宣称全面对标完成。
4. **Given** 宣称全部完成，**When** 验收，**Then** 所有纳入题族均有可玩活动或亲子活动及证据，无未处理的覆盖缺口。

### Edge Cases

- 空槽、合法空白 token、跳过、暂存和提交含义不同。
- 重复候选、多解、无解、图形歧义和不完整答案要在发布前发现。
- 记忆阶段切后台、刷新、换题、重播不得偷偷改变展示条件。
- 实质修改题意须保留历史修订记录；纯文案修订不能无故清空完成。
- 开放表达不能依赖孩子输入长句；线下活动不能冒充自动评分。
- 颜色混合、透明叠加、镜像、旋转、遮挡各有独立视觉规则。
- 原资料中的旧招生信息、宣传、成人题和缺失语音须有独立处置。
- 新能力域加入后仍能识别旧世界标识和旧活动位置。

## Requirements

### Functional Requirements

- **FR-001**: 一个应用、连续课程目录；儿童主流程不显式区分 V1/V2。
- **FR-002**: 保留当前 40 个游戏、489 轮的可访问性和稳定身份；可升级原题，但必须复核行为与进度。
- **FR-003**: 以六个能力域组织对标；动作与精细操作作为相应域的亲子活动纳入。
- **FR-004**: 矩阵记录来源页码/时间、当前覆盖证据、目标活动、差距、交互、难度、批次和验收方式。
- **FR-005**: 每个纳入题族声明适用台阶和变式目标。可重复训练题族默认三个台阶、每阶三个有效变式；亲子活动默认至少三个不同条件的活动方案。减少台阶须记录能力/适龄理由及替代验收，不能为凑数加难或用例外隐藏遗漏。已有题通过等价复核后可计入，简单换皮不计。
- **FR-006**: 分阶段支持单选、多选、顺序摆放、格位填充、配对/连线、路径、构形操作和家长观察。
- **FR-007**: 记忆任务明确展示/听取、隐藏、保持、回忆、反馈阶段，时长和支持方式可配置。
- **FR-008**: 按集合、序列、槽位或约束判定答案，支持合法多解，不把所有任务压成一个选项。
- **FR-009**: 新活动具有一致的题面、操作说明、视觉证据、反馈、分层提示和家长追问。
- **FR-010**: 难度使用规则数量、步骤、记忆负荷、表示抽象程度与支持强度描述；阅读和操作负荷另计。
- **FR-011**: 操作支持撤销、替换、重试；拖动有点击选择再放置的等价操作。
- **FR-012**: 开放表达与线下任务提供观察要点，不强制自动语音评分、录音或上传。
- **FR-013**: 中文沿用标准本地语音流程；其他语种使用独立可审计音色，提示/指令/反馈纳入覆盖检查。
- **FR-014**: 运行图片遵循原分类和注册规则；线索清晰，可独立核对。
- **FR-015**: 进度区分完成、尝试、提示、重看/重听、跳过及家长观察，内容重排后仍可续玩。
- **FR-016**: 旧存档迁移可重复安全执行，保留游戏级与题目级历史事实和原数据备份；无法确认旧版本时不猜索引映射，不把游戏完成展开为题目完成，未知字段保持未知。
- **FR-017**: 不支持新交互的平台不得静默降成单选或导出残缺题目；明确发布范围。
- **FR-018**: 资料标题、册号、旧招生攻略不能作为官方来源证明、当前入学规则或年龄难度标准。
- **FR-019**: 记录原资料错误、歧义、缺项、重复和不适宜情境；以原创情境和独立验证的规则制作活动。
- **FR-020**: 首个交互试点为四类交互各六题，共 24 题；后续必须完成全部纳入矩阵，试点不替代全面验收。
- **FR-021**: 家长可调整起点与支持强度；不以一次成功、强制计时排名或招生成功率评价孩子。
- **FR-022**: 最终学习事实和约束答案独立校核，示意图、题干与答案不能靠标题猜测。

### Key Entities

- **来源材料**: 指纹、物理页/幻灯片/时间定位、实际阅读覆盖、配套和重复关系、核验限制。
- **能力题族**: 思维操作、前置能力、难度台阶、当前覆盖、建设决定与验收证据。
- **活动**: 稳定身份、修订、能力、任务、线索、作答方式、规则、提示、反馈及亲子延伸。
- **活动会话**: 当前阶段、操作、支持记录、暂存答案、完成/跳过。
- **学习记录**: 本地档案、活动身份、完成与独立程度证据、家长观察和历史迁移标记。

### Asset & Documentation Impact

- **Assets**: 设计阶段不新增运行资源；实施时按题族更新既有图片分类、注册与本地语音。原参考资料不进入发布包。
- **Docs**: 规格、研究、矩阵、来源索引、数据模型、交互契约、任务和验证指南，以及 AGENTS、宪章、CHANGELOG、TODO、资产和内容规范。
- **Audit Coverage**: 来源/矩阵完整性、课程审计、构建、存档迁移、交互语义、语音覆盖、视觉检查、真实 Mac 安装验收。设计验证不等于课程实施验证。

## Success Criteria

### Measurable Outcomes

- **SC-001**: 121 个文件全部有阅读范围和处理记录，未逐题校核与未完整听取的视频明确标识。
- **SC-002**: 全部纳入题族达到矩阵明确的台阶与变式目标；所有例外均有理由和替代验收，每项能追到规则与证据。
- **SC-003**: 多选、顺序、格位、记忆、约束任务代表场景可完成，合法多解、重复候选和空白选项不误判。
- **SC-004**: 旧完成与原续玩信息全部保留，可确认的映射正确；无法确认的位置显式回退而不误跳，游戏完成不扩写成题目完成。
- **SC-005**: 新内容文字、画面、反馈、亲子提示与语音一致，发布无缺图缺音、失败条目或答案歧义。
- **SC-006**: 校准至少观察 6、7、8 岁各两组亲子共玩，记录操作理解、独立完成、支持使用和解释依据，用于调整难度，不解释为年龄标准。
- **SC-007**: 分别报告来源覆盖、能力覆盖、可玩内容覆盖，不能相互替代。

## Assumptions

- 全面对标指完整识别能力与任务结构，并明确纳入、改编、亲子延伸或仅作参考，不要求逐字复制每一道原题。
- 保留原有约 4 岁体验，新增难度优先按 6–8 岁试玩校准；参考资料并非统一适龄教材。
- 本次交付为建设设计与执行任务，运行时和题库按后续任务分阶段实施。
- 六个能力域不是六个独立应用，也不要求先选年龄版本。
- 延续离线优先与亲子共玩，不新增账号、云端判题或强制录音。
- 新能力先在现有 Web/Tauri 主应用完整实现；抖音当前数字岛通过显式能力门禁保留，不宣称全部同步。
