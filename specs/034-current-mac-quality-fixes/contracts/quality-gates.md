# 验收契约
- 图集: frame source rect对应单张，内部img实际尺寸=外框×rows/columns，不被max-height破坏。
- 库存/最短路径/双点: 忽略目标条件会产生额外可选项；至少一个合法解，支持合法多解，不以作者解等同独立证明。
- 金字塔: 逐格OR/XOR从底层推到顶层；部分正确只能记录检查支持，旧版完成不能成为新版完成。
- 折纸: 右折保留右半，下折保留下半；孔对称展开且用同一标记，无凭空增加/少孔。
- 矩形: 四点构成非零面积轴对齐矩形；同一框去重、可撤销，独立枚举3/6/9。
- UI: 当前Mac三栏内，必要题面、响应、状态和主动作可用；不靠整体zoom或裁切藏掉内容。亲子模式往返保留草稿，保存仍是观察而非自动正确。
