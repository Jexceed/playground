# 71 个探索题族的设计负荷配置

日期：2026-09-24。范围：当前源码的 71 族、597 项作者活动，不含保留的 24 项试点。依据当前生成分支、呈现映射与 032 审计，不重读原 PDF，不扩展为来源全覆盖。机器可读配置见 [difficulty-profiles.json](difficulty-profiles.json)。

**全部值都是设计估计，未经过儿童实测，不是年龄分、能力总分或独立完成标准。** 不能用 stage、题号或技能名称自动推高负荷，也不能把多个分值相加换算为 6/7/8 岁。配置描述当前孩子需要处理的实际任务；本轮六项计划修复另列为假设，完成实现后才可签收。

## 数值含义

- `rules`：同时维持的独立条件/转换规则数。相同规则重复九格不算九条；没有可执行反例的条件不能算已训练。路线的优化目标计入此数。
- `steps`：代表性路径中依赖前一步的推断/操作阶段数，允许其它合法策略。与点击数、图卡数、显示步骤条数分开。亲子任务使用预测、操作、比较、解释的实际阶段。
- `reading`：0 图片/听觉/口述；1 数字、字母标签或字形/编码辨认；2 短词、拼音或短关系文本；3 连续多句文字。默认允许现有语音或家长读题，不把成人阅读说明计入孩子识读；英语听力另记。
- `motor`：0 孩子可口述、成人记录；1 单选/简单指认拿取；2 多选、配对、多格填放或普通实物操作；3 折剪、节拍动作、平衡协调。它是操作类型估计，不是儿童精细动作分。动作数量需附加记录。
- `representation`：图= pictures；符= symbols；实= physical（沿用现类型，包含亲子口述观察）。混合媒介必须另记，不能将听觉能力塞进 reading。
- `prerequisites` 是可以先用小例子验证的概念或技能，不是强制关卡或年龄门槛。

## 配置选择与已知差异

普通 9 项题族按三个连续活动组取 profile。E02、E04、E08、P03、P04、P05、P06 各只有 3 项，当前 `three()` 传 index 0–2 给 `base()`，导致运行时全部 stage=1。它们在下表按现有三项任务各给一个配置，**必须按活动索引取值**；三个 profile 不代表已验证递增难度，也不能静默重写旧进度的 stage。JSON 为每项列出 `activityIndices` 与 `runtimeStageAtBaseline`。

A05 第二阶前两篇事件卡主要为文字（reading=2、symbols），第三篇有三张图片映射（reading=0、pictures）；A08 第9项是拍手/编节拍的亲子活动，应使用 JSON 的活动级覆盖，不能继承前两项声音排序的配置。G20 的关系条数应根据实际可见遮挡图动态读取，移除传递冗余后计数，同时保留原始关系数用于审计。

## 建议动态补充的字段

1. **实际项目量**：候选数、需选数、需填格数、配对数、构件数、运动步数。G19 的9/16/9格、A06 的9/15/21候选、N04/N13 的密集候选不应靠增加 `steps` 表达。
2. **记忆协议**：项目数、对象—数量/位置绑定数、顺序与逆序、观察/保持时长，以及重看、重听、提示和中途检查实际使用。A04/A08 的 `preview` 为空，但序列长度分别是2/3/4；不能把 `preview.length || stage` 当真实记忆负荷。A07记录有效规则与切换，A05记录故事刺激信息量和实际回答需求。
3. **有效条件**：路线合法长度集合、并列最优数，库存约束是否改变合法集合，图形干扰是否使每条规则有区分力。L12当前候选边没有交叉可能，虽然判定引擎支持不可交叉，也不把这条算作已训练。
4. **支架与中间结果**：G07依赖深度、合并节点数、是否外显；G09网格大小、期望长方形数、标记工具可用与实际使用。工具存在与儿童使用是两项事实。
5. **媒介与语言**：主要图/文/实物之外，附加 `audioLocale`、需懂词汇、需同时理解关系数及翻译/家长读题协助。E06/E07的 reading=0不能解释成英语零负荷。
6. **动作类型和量**：记录单选、多选、连续配对、旋转定位、画标记、折剪、托盘行走、节拍；parentObservation不能统一 motor，成人提交观察表也不能算孩子的动作表现。

## 接入与校准边界

先按 family/profile 建立显式配置，再按活动结构/例外覆盖，不要再次以 stage 自动填全部字段。开发期检查71个家族键、每族3个profile、597项均命中、上述7族索引映射和混合交互例外。估计与儿童观察要分字段保存：`assessmentStatus=design-estimate-not-child-tested`，年龄观察样本、日期、实际支持和错误类型另存。6/7/8岁的观察应检查先修、是否理解规则、是否能操作、是否需要重看或成人协助，以及孩子给出的理由；在收到真实观察前保持“未实测”。

本研究只读应用源码与已有报告，未运行UI、未改应用、未作儿童试玩、未重新逐条听音或阅原PDF。源码定位是研究开始时行号；后续修改应以 family 的 `set(...)` 生成分支定位为准。
