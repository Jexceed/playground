# 057 缺口补一补轮廓重绘

## US1 P1 精致且能看清
重绘本组8题的10种轮廓（含选项），统一流畅曲线、线宽、比例和留白。题图使用连续实线，只在指定位置缺一段；取消整圈粗虚线。选项与题图使用同一几何源，苹果顶部缺口同时包含顶边与叶子，鱼右侧实际缺尾巴。放大显示，保留已有题卡框架和按钮。

## US2 P1 关系准确
单一缺口必须是闭合路径上一段连续区间，不能只是通用遮罩没碰到主体。完整答案包含题图全部保留边；花朵用统一外轮廓，苹果/梨/鱼等形体可辨。题目文字、ID、顺序、答案、进度及其他图形题保持一致；不填出缺失边或提示正确字母。

## US3 P1 可交付
全组逐图复看、运行相关回归、build和curriculum审计。导出语音确认文字未变，无需重合成。mac:install并查看8道真实题面，保存代表截图，恢复原位置且不新增完成记录。
