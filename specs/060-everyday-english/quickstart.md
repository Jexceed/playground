# Validation Guide

1. `pnpm dev` 后进入探索/语言花园；确认三个新题组和旧题组并存。
2. 依次检查六个情境：早晨问候、告别、感谢、抱歉、喝水、求助。听英文选项，答错/改选/答对；正确后听示范，确认不清空成绩。
3. 打开对应亲子活动，交换说话角色，记录 supported/notYet，不产生自动口语得分。
4. 完成原英语听辨题，点击完成后的复听入口，确认原英文仍可播放。
5. 运行 plan.md 所列构建/审计/语音/回归命令；运行 `pnpm mac:install` 并打开 `/Applications/小小思考屋.app` 验证。
6. 记录资源审计与实际验证，不把成人测试写成儿童试玩。
