# Validation
1. pnpm dev打开本地应用，探索→语言花园→词语有朋友。交叉配对，改连，断开，撤销，清空；从右侧开始；键盘操作。
2. 探索→逻辑屋→关系接力第7题：4对图卡，检查交叉线与图片大小；窗口改为375px，连线仍对准端点。
3. 小岛连桥：直接点图面，检查0/1/2条桥与现成桥下限；点击两个岛改桥；提交代表正确答案。
4. 路线设计师第7题：分别走直路和弯路；确认当前位置、方向、不能跳跃/重走，撤销正确恢复。
5. 跑plan中测试、构建与审计，记录失败和修复。改文案后完成语音增量生成和审计。
6. pnpm mac:install，打开新构建的真实app，完成配对和桥/路图面操作。不要覆盖用户正在玩的窗口；发现控制冲突即停止并记录。
