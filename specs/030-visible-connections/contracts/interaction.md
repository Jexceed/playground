# UI contract
- 卡片为button，连接可从左右任意方向开始；Enter/Space与点击等效，Escape取消。
- 拖动松到另一侧卡片才提交一个response；松到空白、原卡或同侧不改response。
- 线有实际可见端点和连续路径；端点坐标来自卡片布局，不依赖答案或固定屏幕像素。
- 已连卡提供具名断开按钮；单次重连是一项可撤销动作，旧配对完整恢复。
- 图上边有具名键盘热区，节点可选择相邻目标；路线多条平行边必须选择具体路段。
- 固定桥下限、桥上限、路线连贯/阻断/重走规则只约束合法操作，不自动完成推理。
- disabled后所有输入冻结；颜色不表示答案正确性。操作状态有aria-live文本补充，但视觉不依赖该文本。
