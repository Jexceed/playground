# Feature: 看得见、点得中的连接题

**Date**: 2026-09-22 | **Branch**: local `dev`

## User problem

用户反馈新题库的连接题非常不直观。当前配对只用文字和编号表示关系；桥和路线要离开图面寻找 A—B 按钮，双桥也只画一条线。连接动作、操作位置和结果应当在同一张图上。

## User stories

### US1 · P1 · 直接把图卡连起来

孩子能拖动两边图卡，或依次点击两张图卡，看见真实连线。任意一边可作为起点；选中起点后对侧有清楚提示。每张卡只连接一个伙伴；改连替换被占用的连接，撤销可以完整恢复。已连卡可直接断开。文字图卡只显示一次文字。

验收：2、3、4 对、交叉线、错误配对均可见且可改；未提交不提示答案。拖出面板、同侧松手、Escape、窗口失焦只取消临时操作。触屏、键盘和桌面均可完成；撤销/清空/切题无残留线。

### US2 · P1 · 在地图上搭桥和走路

孩子直接点图中的桥/路段操作；可点击相连小岛/地点操作，无需对照图外字母按钮。双桥画成两条线；岛上展示需要数与当前数。路线显示当前位置、可走路段、已走方向和被阻断路段。平行直路与弯路保持独立可选。

验收：现成桥不能被移除；每次操作符合 max/fixed；路线不能跳跃、走封路或重复不允许重走的边；撤销保留原语义。

### US3 · P2 · 本地应用体验一致

保留题目身份、答案、进度和启蒙/探索分区；说明与语音同步。375px 与桌面宽度都可操作，真实 Mac app 完成代表流程，安装到 Applications。

## Requirements and boundaries

- 保留题目含义、数量、身份和已完成记录。验收发现 L02 第7–9题有两张相同圆形，补充这两张卡互换的合法配对，修复隐藏 ID 导致的误判；其他答案与评分不变。
- 配对线色只用于追踪关系，不代表正确/错误；界面不得读取 expectedPairs 来选择颜色或限制配对。
- 使用现有本地图卡。交互线、节点、指示器是代码绘制的控件，无新增装饰场景。
- 为连接替换、固定桥、路线合法操作和 session 撤销增加行为测试；记录桌面/窄屏截图和真实 app 验收。
- 必须执行 build、audit:curriculum、语音导出生成审计、mac:install；更新 CHANGELOG/TODO。

## Success criteria

屏幕可直接辨认所有当前连接和可操作目标；每种连接题可通过图面完成；没有水平溢出、错位端点或暗中泄露正确答案。儿童观察仍需后续实际试玩，不由技术验收替代。
