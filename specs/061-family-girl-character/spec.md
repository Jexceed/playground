# Feature Specification: 家庭活动中的 logo 女孩

**Created**: 2026-10-29 | **Status**: Implemented and technically verified | **Branch**: main

## User request

用户在查看“优化小小思考屋并新增英语内容”后，要求家庭活动的任务形象从小男孩改为小女孩，参考 logo 中的人物形象。

## User stories

### US1 — 看见一致的小女孩主角（P1）

孩子进入近期新增的生活英语活动时，早晨问好、放学告别、递还玩具、碰倒积木、请求喝水、拉链求助六幅图中的原男孩，都换成与当前 logo 女孩一致的形象。

验收：深棕黑色高马尾、齐刘海、粉色发圈和粉色背带装搭配米白上衣，保持幼儿比例和温暖绘本画风；求助图保留外套及未拉好的拉链。蓝裙朋友仍能与主角清楚区分。

### US2 — 图、话语和本机应用一致（P1）

家长仍能用原活动追问人物为什么问好、道歉或请求帮助，文字和语音中指向主角的代词与女孩一致。

验收：六图的情境、人物角色、关键物体和动作不变；如需修改代词，则重新导出并生成语音。12 个活动 ID、正确答案、亲子观察方式和既有进度不变。新图可在安装后的真实 Mac 应用中显示。

## Functional requirements

- FR-001：以 `public/images/brand/thinking-house-brand-v3.png` 为身份参考，不修改 logo 本身。
- FR-002：替换六个已注册的 `english-daily-*.png` 场景，保持 1200×675 PNG 和现有路径；保存新生成原图、精确提示词及哈希。
- FR-003：主角改为女孩，家长、老师和蓝裙朋友仍按原情境存在；不得新增文字、箭头、重复图卡或答案标记。
- FR-004：保留原片的太阳/早餐、书包/挥手、泰迪熊递还方向、散落积木、空杯/饮用水壶、未拉好的拉链等证据。
- FR-005：更新图像 alt 和涉及主角的中文代词；英文句子及选择规则不变。中英文语音脚本和 manifest 对齐，failures 为空。
- FR-006：在现有 main 工作区继续；保留之前 060 的未提交内容，不覆盖其他模块。最初只做本地交付；用户已于 2026-10-30 追加授权提交并推送到 origin/main。
- FR-007：完成构建、课程/语音审计、相关现有测试、`pnpm mac:install` 和真实应用目检；儿童试玩继续单独记录。

## Scope and success criteria

本次范围为近期 060 新增的六幅生活英语场景和对应 12 个活动。没有独立名为“家庭活动”的导航模块，按用户引用会话对应的亲子生活情境实施。其他历史图卡和动物角色不在此次修改范围。

成功标准：六幅图中的原男孩全部变为参照 logo 的女孩；没有损失可判断的生活线索；图片、文本、语音和安装产物一致；历史活动身份与进度兼容。
