# 055 棋盘下一步：空格、棋子和试放的语义

## US1 P1 看清棋盘
9题用一个较大棋盘代替数字混在棋子中的参考图和重复缩略选项。已有黑白子有明确实心材质；空格中央不显示编号。圈出的候选空格使用虚线圈和加号，语音说明可以试放；已有棋子不可操作。使用精确代码图形保留格子和棋子关系。

## US2 P1 一次试放一颗，再独立选位置
点候选格只试放一颗带强调外圈的黑子，不直接作答。换格会收回上一颗。用“选这个空格/取消这个选择”记录候选答案；其余已选位置显示勾选而不添加黑子，避免多选被误解为同时落多子。共享撤销清空与原判分保留。小规则图解释横竖斜线三连；夹子题解释黑白白黑的连续夹法。
