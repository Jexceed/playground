# Feature Specification: Mac 最大化窗口启动与全页面文案贴合度优化

**Created**: 2026-11-19 | **Status**: Installed and verified on Mac | **Branch**: main

## Problem

1. **Mac 启动窗口尺寸**：当前桌面端主窗口固定以 `1280×820` 打开，在大屏 Mac 上留白较多；用户希望在 Mac 上打开应用时直接以**最大窗口（填满桌面可用区域，但不是全屏模式）**启动，保留菜单栏、程序坞与标准窗口控制按钮。
2. **各页面文字描述贴合度不足**：逐页审视启动页、页面元信息、左侧主题与题组导航、中间舞台顶部横幅、启蒙与探索题头、探索证据框标题及右侧家长/成长面板后，发现多处文案不贴合或前后矛盾：
   - `index.html` 仍写“为 4 岁孩子和家长设计”，未覆盖现已上线的“启蒙 + 探索（幼儿至小学低年级）”双阶段内容。
   - 启动页副标题“正在打开今天的小小问题”与标题“小小思考屋”重复“小小”，且偏刷题口吻。
   - 左侧主题简介在“启蒙”与“探索”共用同一串文字，导致探索阶段的图形工坊、数字岛、语言花园等简介与实际题组脱节，且展开态 CSS 强制单行省略截断。
   - 左侧题组区混用“世界 / 主题”“关卡 / 题组 / 个 / 组”，且在搜索无匹配结果时错误显示“这个世界的关卡正在制作”。
   - 中间顶部状态条固定显示静态总览文案，亲子观察活动页仍显示“组合线索，多步思考”；启蒙主舞台未显示当前题组名称，难度提示写着生硬的“难度判定：”，时钟场景标签写“活动”，重置题组按钮“从头来”易被误认为只重做当前题。
   - 探索证据框标题将找长方形网格、练习日历、物品集合、购物找零、面额兑换等静态图面统一显示为“看看发生了什么”；亲子观察活动底部显示“这次尝试 0 次”；右侧家长面板内层标题与折叠标题重复，非记忆题显示“重看或重听 0 次”，且直接暴露“尚待真实亲子试玩校准”等内部工程术语。

## User Stories

### US1 — Mac 启动即最大化窗口且非全屏（P1）

在 Mac 上启动“小小思考屋”时，主窗口自动扩展到当前屏幕的最大可用窗口范围（`visibleFrame`），不进入 macOS 原生全屏空间（`AXFullScreen = false`），菜单栏、程序坞和窗口左上角控制按钮保持可见，用户仍可正常还原或调整窗口大小。

### US2 — 全页面文字描述准确贴合当前情境（P1）

从启动页、左侧阶段/主题/题组导航、搜索空态、中间舞台顶部说明、启蒙与探索各题型题头与证据说明，到右侧家长陪玩提示与本机成长记录，所有界面描述均与当前所在阶段、主题内容、题型玩法和亲子共玩理念一致，不截断、不自相矛盾、不暴露内部工程话术。

### US3 — 原有题库、语音包与学习进度零退化（P1）

不改动已审定的 118 组 / 1,122 题题库数据、答案契约、本地进度存储结构及 4,499 条本地 Edge 语音资产；所有课程审计、语音媒体审计、构建与回归测试保持通过。

## Requirements

- FR-001：在 `src-tauri/src/main.rs` 中针对 macOS 启动阶段对 `main` 窗口调用 `maximize()`，保持 `tauri.conf.json` 中 `fullscreen` 未开启、`acceptFirstMouse: true` 及原有默认/最小尺寸（供退出最大化时还原及跨平台使用）。
- FR-002：更新 `index.html` 与 `LaunchSplash` 描述文案，体现面向幼儿与小学低年级家庭“看图、动手、说说为什么”的亲子共玩定位。
- FR-003：左侧导航按“启蒙 / 探索”各自真实题组提供贴合的主题简介并取消单行截断；统一“主题 / 题组”术语；修复搜索无结果时的空状态文案并提供一键清空搜索。
- FR-004：中间顶部横幅按当前阶段、主题与活动类型展示贴合的引导说明；启蒙题头补齐当前题组名称，优化难度说明前缀、时钟场景标签与题组回第 1 题按钮文案。
- FR-005：探索题头区分“英语日常说”中的看图选句与亲子对话，明确末题跳回补做文案；按证据模型类型细分 `ActivityEvidence` 标题语；亲子观察活动底部不再显示“尝试 0 次”。
- FR-006：右侧家长提示与成长记录消除重复小标题，区分亲子观察活动与常规练习的陪玩说明，将内部校准术语改为温和家长提示，仅在记忆题或已有重看记录时展示重看/重听计数，并补充题组完成数展示。
- FR-007：完成 `pnpm build`、`pnpm audit:curriculum`、`pnpm audit:voice-media`、相关回归测试及 `pnpm mac:install`，打开真实 `/Applications/小小思考屋.app` 核验窗口尺寸与非全屏状态，并更新 `docs/CHANGELOG.md` 与 `docs/TODO.md`。

## Success Criteria

1. `/Applications/小小思考屋.app` 冷启动后窗口填满屏幕可用区域（`visibleFrame`），且 `AXFullScreen` 为 `false`。
2. 各页面、侧栏、题头、证据框和家长/成长面板文案与所在页面内容一一贴合，无截断省略号、无“关卡正在制作”误报、无工程术语外露。
3. 构建、课程审计、语音媒体审计与回归测试全部通过。

## 审查复测标准

- 在桌面与窄屏切换主题，两阶段共九个主题各自的当前简介可见、可读，未选主题保持紧凑。
- 在语言花园输入“看图选句”或“亲子对话”可找到含该玩法的英语题组。搜索无匹配时，两种布局都显示空态并可一键清空。清空后显示原题组和当前选择。
- 在亲子共玩、填写和保存三个阶段，家长提示均可照做。查看提示或跳过后仍能区分待记录与已记录的观察。
- 比较题横向并排和窄屏纵向排列时，标题均与画面一致。启蒙的回第 1 题、记忆朗读和场景回看的既有浏览器验收可继续运行。
