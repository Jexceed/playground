# UI Contract: Landscape Workbench

## Root

- 运行方向：`landscape`
- 设计基准：1280×720
- 背景：浅暖色底 + 低对比度网格/光斑，不抢题面注意力
- 主体：安全区内三个纵向卡片栏，间距一致

## Left Column

从上到下：

1. 本地品牌图和“小小思考屋”识别区
2. 数字岛激活卡：名称、简短说明、总进度
3. “数字岛关卡”标题
4. 八个游戏按钮：图标、标题、目标摘要、完成数；当前游戏使用金色高亮

Action: `openGame(gameId)`

## Center Column

从上到下：

1. 题头：`第 n/N 题`、难度、游戏名、听题按钮
2. 题干和操作指令
3. 蓝绿色视觉线索板，内部使用既有题型渲染器
4. 横向答案选项；选中态为金色描边/底色
5. 底部操作：重置、检查/下一题
6. 反馈条：错误提示或成功解释，不覆盖题面

Actions: `hearRound`、`selectOption`、`restartRound`、`checkAnswer`、`nextRound`

## Right Column

从上到下：

1. 题号卡：全部题号网格；当前题金色、已完成绿色
2. 家长提示卡：当前题追问 + 听提示
3. 成长记录卡：能力标签，溢出时显示数量摘要
4. 家长说明/侧边栏入口

Actions: `jumpToRound(index)`、`hearParent`、`openParentInfo`、`openSidebar`

## State Rules

- 启动：恢复最近位置；没有位置则 `game[0]/round[0]`。
- 切换游戏：打开该游戏最近未指定时的第一题。
- 跳题：立即停止语音、清空选择与反馈、保存位置、渲染新题并自动播题（语音开启时）。
- 检查前：没有选择时主按钮不可用。
- 错误：反馈可见、允许重新选择，不标记完成。
- 正确：标记完成、能力标签更新、主按钮变为下一题。
- 最后一题：完成后保持在统一工作台，不切回另一种页面。

## Viewport Acceptance Matrix

| Physical viewport | Required result |
|---|---|
| 667×375 | 三栏可辨识，主操作可达，核心文字无裁切 |
| 844×390 | 完整题面与右侧题号可见 |
| 932×430 | 增加留白但不放大到破坏层级 |
