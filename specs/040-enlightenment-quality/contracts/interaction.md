# UI contract

- The child can listen before starting a timed glance. Start/review controls communicate the observation phase; answer options and submit reflect its gate.
- Reviewing clears the pending answer; hidden cues stay hidden through feedback unless intentionally reopened. Round navigation resets transient observation state.
- Grading compares semantic values; option reordering never changes the intended correct figure/value.
- Completion and displayed practice tags derive only from actual completed round IDs. Existing local completion history stays intact.
- Numeric evidence reflects the current quantities; illustrative scenes cannot display a conflicting fixed example as the active task.
- The installed Mac uses the same compiled assets as the verified build. Record UI checks separately from build/audit success.
