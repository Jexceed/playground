# Decisions

- Decision: audit current data and rendering together. Rationale: the existing audit checks schemas and many known examples but cannot prove all narrative evidence is sufficient. Alternative: treating a green audit as complete was rejected.
- Decision: preserve stable IDs and historical completion facts. Correct wording/evidence without converting old completion into new mastery. Alternative: deleting or resetting progress would lose valid history.
- Decision: use child-triggered observation readiness and explicit re-observation. Rationale: the current last-five subitizing timer runs on entry before readiness; the same choices are currently live while dots show. Alternatives: longer unconditional timer or removing the memory challenge do not address fairness.
- Decision: preserve working local illustrations and exploration behavior. Where a fixed decorative scene conflicts with variable counts, use the existing exact count surface as the source of evidence. No arbitrary replacement pictures.
- Decision: use deterministic but noncyclic option order with stable semantic values. Rationale: current correct positions repeat A/B/C; graphic letters must be re-associated with their figures after reordering.
- Existing native WebKit behavior and real installed testing are essential; Chromium dimensions alone are insufficient. No new library or external technology decision is needed.
