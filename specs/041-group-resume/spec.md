# 每个题组独立续玩

## User request

启动小小思考屋或重新选择一个题组时，直接回到该题组上次停留的题，不要每次回到第一题。

## User stories

- US1 (P1): 孩子在同一部分切换两个题组、切换主题或重新点击当前题组后，每个题组保留各自最后停留的题号。没有历史的题组从第一题开始；明确点击“从头来”仍可回到第一题。
- US2 (P1): 退出并重新启动应用后，恢复上次的部分、主题、题组和题号；之后打开其他已访问题组，仍能恢复其位置。启蒙和探索独立保存，旧版已知位置可迁移。

## Requirements and acceptance

- R1: 以稳定 gameId / roundId 持久化每个题组的最后访问位置；同一题组重选不清空当前操作。两部分均适用。
- R2: 启动恢复最近位置；切换题组、部分、主题不得用默认第一题覆盖另一题组的记录。点击已激活的主题不重新选首个题组。
- R3: 迁移当前按部分保存的导航，以及已有旧格式位置；保留原始完成记录、尝试、提示等事实。未知历史不由完成题数推测。未来或损坏的导航数据不得被静默覆盖。
- R4: 题目重排后按稳定 ID 恢复；某题被移除时回到同一题组第一题；某题组被移除时安全回到所属部分的有效默认题组。
- R5: 恢复时不先呈现第一题的题面或观察状态。计时/听力任务仍遵守原有准备与隐藏要求。
- R6: 通过持久化回归、构建及课程审计；安装并在真实 Mac 应用验证题组往返与退出重开。更新 CHANGELOG/TODO 和验证记录。

## Scope and constraints

保存题目位置，不新增作答草稿自动保存、云同步、推荐下一道未完成题或题库改动。主题切换沿用选择该主题首个题组的既有行为，但恢复该题组自己的题号。明确的重玩/从头来操作仍允许重置位置。题干、语音和配图不变。工作在当前 dev worktree，不修改 main 的独立文件。
