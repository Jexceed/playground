# 巡检决策
- A05第4/5题六事件仍textOnly；已有第6题种植图不适用这些角色/事件。生成对应事件，保留听完后才可作答。
- P01物品有图片，九用途仍纯文字。生成真实动作，独立放大不参与连线。拒绝把左侧物品直接复制成右侧图片。
- E04三题复用相同“图卡、纸笔”材料，与第二题搭桥及第三题水杯证据不符。分别提供四张故事素材选三张、实物搭桥材料与已有水杯场景；不把图片当成因果定论。
- L07亲子九色形图卡映成小猫头像；G16圆柱映成普通积木、透明杯映成不透明杯。采用明确材料键及精确图示，移除宽泛图卡映射。
- P06要求沿粗线操作却不提供模板；给可照画模板，继续实物折剪。
- 数学/空间题的可数点、棋盘、方格、阴影与几何关系是有效证据，保留确定性图。家庭照片/地图活动仍由家长选真实资料。新材料插画仅说明准备什么，不预画浮沉/影子结果。
