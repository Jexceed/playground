# 小小思考岛

> 每天一个故事，陪她想一想为什么。

当前执行状态、并行分工和下一批任务见 [[小小思考岛-推进记录与并行任务计划]]。

这个项目不是做刷题软件，而是做一个适合 4 岁孩子的亲子互动故事游戏。重点不是让孩子快速答对，而是让她通过看见、操作、预测、解释和复述，慢慢形成长思维。

## 2026-06-28 修订：先聚焦数字与逻辑

第一阶段暂缓语文和英语，只做两条主线：

1. 数字岛：数感、比较、合成分解、加减情境、公平分配。
2. 逻辑屋：模式、顺序、因果、两三步计划。

重要修正：

- 不从“5 条鱼分给 2 只猫”这类有剩余的题开始。
- 公平分配先从“4 分给 2”“6 分给 2”“6 分给 3”这种明确能平分的情境开始。
- 每个主题都要有多题递进，不能只有一个孤立小游戏。
- 玩法要借鉴成熟早期数学学习轨迹：先具体操作，再图像理解，再语言解释，再迁移。

参考框架：

- Common Core Kindergarten Math：Counting and Cardinality；Operations and Algebraic Thinking。
- Learning Trajectories early math：subitizing、counting、composing/decomposing、problem solving。
- NAEYC DAP：以发展适宜、游戏化、亲子互动为主。
- Numberblocks：用角色和故事解释数、加减、组合，而不是直接讲公式。

## 2026-06-28 补充：执行功能与长思维游戏

参考新的游戏方案后，逻辑屋不只做“找规律”和“排序”，还要覆盖执行功能：

- 抑制控制：看到冲动答案时先停一下，例如红灯绿灯、反着来。
- 工作记忆：记住两三步指令，例如先拿钥匙，再开门。
- 认知灵活性：规则会变，例如先按颜色分，再按形状分。
- 计划与回顾：先预测，再尝试，再说为什么成功或失败。
- 证据推理：看线索，而不是乱猜。

这些方向可以借鉴：

- Harvard Center on the Developing Child 的 executive function 活动建议。
- HighScope 的 plan-do-review 思路。
- Learning Trajectories 的早期数学轨迹。
- 亲子提示卡：每关结束都让孩子说出“我为什么这么选”。

## 2026-06-29 修订：声音、布局与画风

当前原型暴露出三个问题：

1. 浏览器内置中文 TTS 声音机械，不适合 4 岁孩子。
2. 页面布局需要更稳定，让孩子知道哪里看题、哪里点答案。
3. 系统 emoji 混搭导致画风不统一。

处理原则：

- 真实录音或 TTS 生成文件优先；没有文件时，临时使用系统中文语音兜底，保证原型阶段每个部分都有声音。
- 声音分两类：
  - UI 音效：点击、正确、提示、错误。
  - 逐句配音：题目、反馈、鼓励语。
- UI 音效可以从素材库找，逐句配音建议用家长录音或统一 TTS 批量生成。
- 布局固定为：顶部关卡信息，中间题目画面，底部答案区和操作按钮，右侧家长提示。
- 配图先用统一的“柔和漫画 / 蜡笔贴纸”风格，避免抽象几何块；孩子必须能从图形本身识别草莓、苹果、小猫、小河等对象。

候选声音来源：

- Pixabay Sound Effects：适合找短 UI 音效，标注 royalty-free、no attribution required。
- ZapSplat：音效库丰富，免费用户通常需要署名，商用前要看具体 license。
- Freesound：音源多，但 Creative Commons 许可复杂，必须筛 CC0 或确认 attribution/noncommercial 限制。
- OpenAI / Azure / Google TTS：适合批量生成每道题的配音，但要统一声音、人设、语速和文件命名。

推荐落地：

1. 第一阶段先不用背景音乐，避免干扰思考。
2. UI 只保留 3 个短音效：tap、success、error。
3. 题目、图形物体、答案选项、正确反馈都要可点击配音。
4. 题目配音用一个温柔女声或家长真人录音。
5. 每条语音控制在 2-5 秒。
6. 文件放在 `public/audio/voice/zh-CN/female-warm/`。
7. 所有配音最终都离线生成成 mp3，不在孩子使用时实时 TTS；浏览器 TTS 只作为原型兜底。

## 孩子背景

- 数学：学过 Numberblocks 前三季，会简单加减，少量接触乘除。
- 中文：会说中文，会背古诗，认识一小部分字。
- 英文：认识字母和简单单词，学过 Oxford Tree、自然拼读 1、Kids Box 1。

## 产品定位

[[小小思考岛]] 的核心定位：

- 亲子共玩，不是孩子独自刷题。
- 每局 3-8 分钟，短任务，但保留连续故事。
- 图、文、语音、拖拽和点选结合。
- 每个知识点都尽量回答“为什么”。
- 不做排行榜、金币商城、连续打卡压力。
- 成长记录用能力标签，而不是分数。

## 能力阶梯

| 层级 | 能力 | 游戏表现 |
|---|---|---|
| L1 感知 | 看见数量、颜色、声音、动作 | 这里有几只小猫？ |
| L2 配对 | 图、词、声音、动作对应 | “鹅”对应白鹅图 |
| L3 分类 | 按规则分组 | 会飞的放一边，不会飞的放一边 |
| L4 比较 | 多、少、一样、长短、高低 | 哪边苹果多？ |
| L5 解释 | 说出为什么 | 因为又来了两个，所以变多了 |
| L6 计划 | 多步完成任务 | 先找钥匙，再开门 |
| L7 迁移 | 换场景仍理解 | 分鱼会了，分饼干也会吗？ |

4 岁阶段重点放在 L1-L5，少量引入 L6。L7 主要靠家长追问，不强求。

## 第一阶段两个世界

### 数字与逻辑岛

目标：理解数、加减、比较、分配、规律、因果。

玩法方向：

- 数字积木：用物体合并理解加法。
- 小商店：用买水果理解数量变化。
- 公平分一分：先理解刚好一样多，再慢慢引入剩余。
- 平衡天平：理解一样多。
- 找规律：红蓝红蓝、大小大小、1-2-1-2。

### 逻辑屋

目标：模式识别、顺序、因果、规则切换、抑制控制、计划和证据推理。

玩法方向：

- 找规律火车：红蓝红蓝、一大两小、太阳月亮星星。
- 先做什么：拿杯子再倒水，找钥匙再开门。
- 两步计划：先搭桥过河，再拿胡萝卜。
- 故事三格排序：开始、变化、结果。
- 会变规则的分类机：按颜色分、按形状分、反向规则。
- 红灯绿灯小动物：正常规则和反着来。
- 谁拿走了蛋糕：看证据、排除不合理答案。
- 桥怎么搭：预测、尝试、调整。

## 暂缓内容

### 古诗与中文小剧场

目标：从会背古诗，走向理解词语、画面、动作和情绪。

玩法方向：

- 古诗拼图：一句诗对应一个画面。
- 词语点亮：点“明月”，画面里的月亮发光并播放解释。
- 诗句排序：把四句诗按画面发展排好。
- 小演员模式：给诗里的角色配音。
- 找不同：诗句和画面不一致时找出来。

### 英语声音探险

目标：自然拼读、开头音、CVC 单词、短句和动作对应。

玩法方向：

- 字母声音屋：点 b，听 /b/，找 ball、bee、bag。
- 押韵火车：cat、hat、mat 上同一节车厢。
- 单词拼拼看：c-a-t 三个音拼成 cat。
- 听指令行动：Put the apple in the box.

### 长思维任务屋

目标：训练连续推理、计划、工作记忆和因果链。

玩法方向：

- 做蛋糕：先找材料，再按顺序放，最后烤。
- 小医生：先问哪里不舒服，再选工具，再治疗。
- 修桥过河：木板数量有限，要想怎么铺。
- 宝藏地图：根据 3 条线索找到目标。

## 第一阶段 MVP：数字与逻辑题组

第一版不再按“10 个小游戏”推进，而是按“递进题组”推进。每个题组包含多道题，从明确到复杂。

当前实现状态：

- 数字岛：6 个题组，137 题。
- 逻辑屋：6 个题组，145 题。
- 总计：12 个题组，282 题。
- 每题都有：题干、图形/场景、选项、正确反馈、重试反馈、家长追问。
- 当前导出 604 条唯一语音脚本，可用于真人录音或 TTS 批量生成。这里的 604 是配音文本条数，不是题目数。
- 题目导航已从主游戏区移到侧边栏：孩子主要看中间题面，家长可以在右侧直接跳题并查看已做题目；小屏幕下导航排到游戏区下面。

### 题组 1：数一数小路

目标：

- 一一对应。
- 最后一个数代表总数。
- 1-5 小数量辨认。
- 数字和集合配对。

### 题组 2：多一点，少一点

目标：

- 多、少、一样多。
- 一个对一个比较。
- 5 以内合成分解。
- 4 可以分成 2 和 2。

### 题组 3：来了，又走了

目标：

- 加法是“来了、添上、合起来”。
- 减法是“走了、拿走、变少”。
- 用故事复述数量变化。

### 题组 4：公平分一分

目标：

- 从 4 分给 2 开始。
- 再到 6 分给 2。
- 再到 6 分给 3。
- 暂不从有余数题开始。

### 题组 5：找规律火车

目标：

- ABAB。
- ABB / AAB。
- 三元素循环。
- 说出“这一组是什么”。

### 题组 6：先做什么

目标：

- 生活顺序。
- 因果关系。
- 两步计划。

### 题组 7：魔法数字盒

目标：

- 输入和输出比较。
- 加一、减一。
- 发现“每次都加一”的规则。

### 题组 8：会变规则的分类机

目标：

- 按颜色分类。
- 按形状分类。
- 规则切换。
- 反向规则：找不是红色的。

### 题组 9：红灯绿灯小动物

目标：

- 按规则行动。
- 看到红灯能停住。
- 玩“反着来”，训练抑制控制。

### 题组 10：故事三格排序

目标：

- 开始、变化、结果。
- 因果链。
- 用“先、然后、最后”复述。

### 题组 11：谁拿走了蛋糕

目标：

- 看证据。
- 排除法。
- 区分“线索”和“确定证据”。

### 题组 12：桥怎么搭

目标：

- 空间判断。
- 先预测再尝试。
- 失败后调整计划。

## 配音生产管线

当前原型阶段：

- 题目喇叭：读题干和指令。
- 图形卡片：点击读物体名称。
- 答案按钮：点击读选项。
- 答对反馈：自动朗读。
- 如果没有本地 mp3，临时使用系统中文语音兜底。

录音/TTS 生产：

```bash
pnpm export:voice-lines
```

输出：

```text
public/audio/voice-lines.json
```

建议录音风格：

- 温柔成年女声或父母真人声音。
- 语速 0.85 左右。
- 每句话 2-5 秒。
- 发音清楚，停顿自然，带一点笑意。
- 不要夸张动画片腔，避免孩子只被声音刺激吸引。

## 通用游戏壳

第一版游戏壳支持：

- 显示主题地图。
- 显示关卡标题、目标和家长提示。
- 显示题组进度。
- 显示图像化题目。
- 支持点选答案。
- 支持语音按钮。
- 给出温和反馈。
- 记录完成状态和能力标签。

## 亲子提示卡

每关都附带家长追问句：

- 你为什么觉得这样更公平？
- 如果再来一个，会发生什么？
- 你能换一种方法吗？
- 这个词在诗里是什么意思？
- 这个声音还像哪个单词？

提示卡的原则：

- 不直接问标准答案。
- 优先问“为什么”和“如果”。
- 鼓励孩子说出自己的理由。

## 成长记录

不显示分数，显示能力标签：

- 今天能比较两组数量。
- 今天尝试解释原因。
- 今天能听出 /m/ 的开头音。
- 今天完成了一次三步计划。

## 技术路线

第一阶段使用 Web/PWA：

- 前端：React + Vite。
- 数据：JSON 配置关卡。
- 交互：触屏友好的点选、拖拽、按钮。
- 语音：优先播放本地生成/录制文件；缺失时用优化过的浏览器语音合成兜底，长句自动拆短句朗读；同时导出 `public/audio/voice-lines.json`，后续可以批量录制或替换为真人音频。
- 存储：浏览器 localStorage。
- 发布：先本地运行，后续可部署到静态站点或封装 iOS。

## 制作顺序

1. 完成数字与逻辑 12 个题组，每类 100+ 题。
2. 统一画风为原创幼儿漫画/蜡笔风，不复制商业 IP 角色。
3. 把所有不适合幼儿阅读的文字提示补成图形和可点击配音。
4. 把“点选答案”逐步升级为“可操作物品”，例如拖动、轮流分、排顺序、搭桥。
4. 观察孩子真实反应。
5. 根据反应决定是否恢复语文和英语模块。

## 观察记录模板

- 她笑了吗？在哪里笑？

- 她有没有主动说“为什么”？
- 她更喜欢拖拽、点选、听故事，还是角色对话？
