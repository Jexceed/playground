## 产品决定

继续使用一个“小小思考屋”。孩子按主题和难度进入活动，新旧内容形成连续路径，界面不设置V1/V2或两个版本入口。
原有约4岁内容与进度保留，新增挑战首先面向6–8岁试玩校准。年龄用于推荐；难度由规则数、步骤、记忆负荷、表征和支持程度决定。

代码采用同一应用壳、共享交互/判定/语音/进度，课程按能力域与题族分模块。当前统一目录在src/curriculum/catalog.ts，保留src/data/games.ts旧题并接入src/curriculum/pilot/。完整领域拆分与更多引擎仍按计划推进。

## 资料盘点与阅读口径

用户指定资料共121文件：56 PDF、1301个PDF物理页、47张习题照片、16段视频、1份Word、1份PPT。
Word有40个嵌入图片，渲染为20页；PPT共25页。视频总长约96分19秒。
完整文件指纹、来源路径、处理去向及实际阅读范围见[来源索引](../specs/029-curriculum-benchmark/source-index.md)。

本轮做了全量清点和题族研究，采用可读文本、扫描页联系表、关键页放大及题本/答案交叉核对。
这不等于1301页逐题求解。视频每段抽看三个时间点，共48帧，没有完整听取音轨。逐题答案与缺失音频的核验仍是内容制作门禁。
PPT部分中文在转换时未正常显示，已用原文件文字提取结果与图形交叉阅读；不把缺字渲染当完整题干。

题本、答案、分卷及照片有语义重复，不能按文件名“100/200/1000题”累加。百花部分封面标4–7岁，计算视频标5–6岁，复杂图推含成人招考式规则；这些材料提供能力与题型参考，不能直接证明6–8岁难度或当前学校要求。

## 六个能力域的建设范围

| 能力域 | 核心建设内容 |
|---|---|
| 数与量 | 数量结构、守恒、分合、凑十破十、等分与剩余、序数、数列、代换、钱币、时钟日历、自然测量 |
| 关系与逻辑 | 多角度分类、类比、传递排序、条件排除、填格、路线、连桥网络、学习新规则、状态追踪与棋盘策略 |
| 图形与空间 | 多属性序列/矩阵、位移旋转镜像、布尔叠合、层次顺序、几何关系、拼搭、折剪、立体视图/展开、点阵构造 |
| 记忆与注意 | 集合、位置、顺序/逆序、关联数量、听觉与故事记忆、声音/节奏、视觉搜索、抑制与规则切换 |
| 语言与表达 | 动作词/词义、完整句、故事排序复述、创编与理由、字音对应、英语听辨和交流 |
| 生活与探究 | 用品功能、自然生长、浮沉/颜色/影子/切面、感官与社会情境、文化、亲子动手与动作协调 |

矩阵共74项，71项纳入建设（含亲子活动），3项仅作参考边界：成人复杂公式技巧、复杂斜截面、历史招生与宣传。
每项都给出来源定位、现有游戏基础、建设目标、交互、递进和批次。参考边界中的可迁移简单操作已归入对应建设题族，不一并丢弃。

原有基线是40游戏489轮；首批接入后为44组513题，其中数字岛122轮、逻辑屋337轮、图形工坊54轮。很多现有名称对应的是入门版本：
例如“图形补一补”实际6轮，“桥怎么搭”是条件下选材料，并非满足各岛度数与全连通的连桥网络。
因此对标状态按实际规则、表征、交互和解释判断，不能仅凭游戏名称计完成。

## 交互与学习流程

新增能力需要多选、顺序回填、多空位填图、关系连线、连桥网络、路径、构形和亲子观察。
记忆任务使用独立的展示/听取、隐藏保持、回忆、反馈阶段；新规则教学还包含示范、引导练习和陌生变式迁移。
重复图卡是否可复用、合法空白与未填、多种正确解、并列最优、撤销和跳过都有明确契约。

举例：

- 连桥：先数现成桥，再补局部桥，最后同时满足度数、至多双桥、不交叉和整体连通。
- 图形规律：从一个属性变化，进入两个独立属性，再验证行列共同规则。
- 记忆：由再认进入顺序/位置重现；重听、重看作为支持记录，不能全算独立完成。
- 表达：孩子描述线索、解释依据、复述或创编，家长根据关键点观察，应用不伪造自动口语分数。
- 动手：保留倒杯、折纸、搭建、模仿等亲子活动，用明确材料和观察要点承载。

可重复训练题族默认三个台阶、每阶三个有效变式；亲子任务默认三个不同条件方案。个别能力若不适合继续抽象，必须记录例外和替代验收。每个活动只有一个主要题族，次级标签不用于重复充配额。

## 建设顺序与分支

1. **M0 本轮完成**：来源索引、题族矩阵、规格、数据/交互契约、实施清单。
2. **M1 兼容底座与试点**：保留旧ID、保护无版本存档、统一课程加载；四类关键交互各6题，共24题。
3. **M2 数理逻辑与空间**：逐族完成相应交互、素材、答案和解释。
4. **M3 记忆语言与生活**：完整听取/记忆流程、开放表达、多语种及亲子动手。
5. **M4 全面验收**：全部纳入题族达标，完成语音、图形、进度、真实Mac应用和亲子试玩。

24题只验证第一批交互，不替代71项建设范围。完整清单共115项，M0设计4项及共享加载/首批题目T009、T024已完成；M1细分状态见[pilot-tasks.md](../specs/029-curriculum-benchmark/pilot-tasks.md)。其余完整范围继续保留。

方案保存在dev的独立工作目录，本地检查点不推送。main继续保留确认过的里程碑；年龄不成为长期分支分工。
