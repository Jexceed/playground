# Generated Runtime Assets

This directory is generated by `pnpm export:douyin-math`.

- Do not hand-edit `data/`, `images/`, `audio/`, or `manifest.json`.
- The source of truth is `src/data/games.ts`, `src/data/imageGallery.ts`, and the registered files under `public/`.
- The exporter only includes Math Island runtime assets. Logic House, Graphic Workshop, and any `source/` asset are forbidden.
- Generated files are committed so Cocos Creator can import a reproducible project, but every change must be reproduced by the exporter and pass `pnpm audit:douyin-minigame`.
